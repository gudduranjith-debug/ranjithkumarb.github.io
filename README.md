# 🚀 Featured Project – Financial Risk Assessment ML System

### 🎓 Project Title  
**Enhancing Risk Management in Financial Institutions through Data Analytics**

A complete **end-to-end machine learning system** to predict customer credit risk for banks and lending institutions.

- Dataset: 15,847 customer profiles, 17 features  
- Models: Logistic Regression, Random Forest, Decision Tree  
- Best model: Random Forest (~78% accuracy, AUC ≈ 0.84)  
- Full workflow: preprocessing → modeling → evaluation → Dash web app
